PM 에이전트 — 시스템 & SW 아키텍처

과제관리 시스템과 경영시스템(PostgreSQL) 두 RDB를 연계해, 자연어 질문을 즉시 시각화로 답하는 PM 에이전트. 코어는 시각화가 아니라 데이터 통합 + 에이전트 추론에 있고, 시각화는 교체 가능한 얇은 어댑터다.

2× PostgreSQL (read-only) 사내 LLM 게이트웨이 baseURL+token Docker · jfrog · Jenkins 폐쇄망 운영
데이터 경계

LLM은 사용자 질문 + 카탈로그 메타데이터(컬럼명·유효값)만 본다. 실제 과제·예산 행 데이터는 사내망 밖으로 나가지 않는다 — 조회·집계는 서버가 PG에서 직접 수행하고, LLM은 "무엇을·어떤 필터·어떤 차트"인 plan만 생성한다.
